# Norii Films portfolio
React (Vite) + Node/Express. Vertical scroll drives a horizontal track 1:1.

    npm install
    cp .env.example .env     # add Gmail + App Password (needs 2-Step Verification)
    npm run dev              # http://localhost:5173
    npm run build && npm start

Edit your content in `src/data.js`. Leave `image`/`video` empty for blank frames; for a video use an embed URL (e.g. https://www.youtube.com/embed/ID).
Settings (top right): dark/light, marker color, grain, cursor, "wonky mode".
